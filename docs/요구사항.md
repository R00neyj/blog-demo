# 요구사항

## 1. 블로그 소개

- **이름**: 노트 한 장
- **소개**: 공부하며 정리한 개념과 메모를 모아두는 곳
- **주제**: 스터디 노트

## 2. 화면 구성

| 번호 | 화면 | 설명 |
|---|---|---|
| 1 | 글 목록 | 전체 노트를 최신순으로 보여주는 화면 |
| 2 | 글 상세 | 노트 하나를 골라 내용을 읽는 화면 |
| 3 | 글 작성 | 새 노트를 쓰는 화면 |

## 3. 글 항목

| 항목 | 설명 | 입력 방식 |
|---|---|---|
| id | 글 고유 번호 | 자동 생성 |
| title | 노트 제목 | 직접 입력 (필수) |
| content | 노트 본문 | 직접 입력 (필수) |
| author | 작성자 이름 | 직접 입력 |
| created_at | 작성 시각 | 저장할 때 자동 기록 |

## 4. 분위기

군더더기 없는 흑백 위주의 미니멀한 분위기
